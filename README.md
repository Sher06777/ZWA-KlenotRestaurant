# 🍽️ Restaurant Reservation System
Full-stack web application for table bookings, built from scratch as a semester project for **ZWA (Web Applications)** at **CTU in Prague (FEL ČVUT)**.

## 🛠️ Tech Stack
- **Languages:** PHP (Backend), Vanilla JavaScript (Frontend)
- **Database:** SQLite / SQL
- **Security:** Password hashing, SQL Injection & XSS protection

## ✨ Key Features
- Secure User Authentication & Registration.
- Real-time Table Reservation logic.
- Admin Panel for staff management.
- Responsive design for mobile and desktop.
